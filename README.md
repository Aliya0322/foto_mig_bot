# Foto Mig Telegram Bot

Telegram бот для фотостудии Миг, специализирующейся на профессиональной фотографии и видеосъемке спортивных мероприятий.

## 🚀 Возможности

- **Онлайн-ассистент** - AI-ассистент Алина на базе Mistral AI для ответов на вопросы клиентов
- **Оформление заказа** - Простая форма для оформления заказа на фотосъемку
- **Обратная связь** - Система обратной связи с клиентами
- **Административная панель** - Поддержка нескольких администраторов для управления ботом

## 📋 Требования

- Python 3.8+
- Telegram Bot Token
- Mistral AI API Key

## 🔧 Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Aliya0322/foto_mig_bot.git
cd foto_mig_bot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` в корне проекта и добавьте следующие переменные:
```env
BOT_TOKEN=your_telegram_bot_token
API_KEY=your_mistral_ai_api_key
MODEL_NAME=codestral-latest
ADMIN_ID=admin_id1,admin_id2,admin_id3
DATABASE_URL=sqlite:///foto_mig_bot.db
```

**Примечание:** `ADMIN_ID` может содержать несколько ID администраторов через запятую (до 3 и более).

## 🏃 Запуск

```bash
python ChatBot.py
```

## 🎯 Функциональность

### Онлайн-ассистент Алина
- Интеллектуальные ответы на вопросы клиентов
- Поддержка контекста разговора
- Специализированные знания о фотостудии Миг

### Оформление заказа
- Сбор информации о клиенте (имя, фамилия)
- Указание названия турнира
- Автоматическая отправка уведомлений администраторам

### Обратная связь
- Отправка сообщений администраторам
- Возможность ответа администратора клиенту
- Интеграция с социальными сетями

### Административные функции
- Поддержка нескольких администраторов
- Уведомления о новых заказах и сообщениях
- Возможность ответа клиентам через бота

## 🛠️ Технологии

- **aiogram** - Асинхронный фреймворк для Telegram Bot API
- **Mistral AI** - AI модель для создания интеллектуального ассистента
- **SQLite** - База данных для хранения пользователей
- **python-dotenv** - Управление переменными окружения
